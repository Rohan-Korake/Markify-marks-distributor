## Smart marks distribution calculator that generates realistic experiment marks to achieve a target average.

## Features

- Smart marks distribution
- Target average calculation
- Real-time results
- Dynamic UI rendering
- Responsive design
- Dark mode support
- Input validation

## Tech Stack

- HTML5
- Tailwind CSS
- JavaScript (ES6+)

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Rohan-Korake/Markify-marks-distributor.git
cd markify
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
